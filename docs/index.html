3. Năm đặc tính điện toán đám mây NIST

1. Tự phục vụ theo yêu cầu

Sinh viên tự tạo Repository và Codespace trên GitHub mà không cần quản trị viên cấp phát máy chủ thủ công.

2. Truy cập mạng rộng

API được truy cập từ điện thoại thông qua URL HTTPS của GitHub Codespaces.

3. Gộp tài nguyên

GitHub sử dụng hạ tầng máy chủ và tài nguyên dùng chung để cấp phát môi trường Codespaces cho nhiều người dùng.

4. Co giãn nhanh

Có thể tạo, dừng và khởi động lại Codespace theo nhu cầu mà không phải tự mua hoặc lắp đặt máy chủ vật lý.

5. Dịch vụ đo lường được

GitHub cung cấp Billing Usage để theo dõi mức sử dụng tài nguyên Codespaces bằng core-hours.
